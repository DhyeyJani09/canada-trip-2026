Mosaic — Photography Gallery Template

Mosaic is a free, photography-forward single-page gallery template for photographers, illustrators, studios, and any image-first portfolio. It features a true CSS masonry grid, instant category filtering, a "load more" reveal, and a custom keyboard-friendly lightbox with prev/next, captions, and a focus trap — all on a minimal near-black gallery canvas that lets the pictures lead. Built on Bootstrap 5 with vanilla JavaScript and no jQuery. Free for both personal and commercial use.
